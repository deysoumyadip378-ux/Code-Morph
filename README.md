# 💻 Code Morph — Polyglot Code Translator

A fast, developer-friendly source code translator supporting 12+ programming languages powered by Groq's `llama-3.3-70b-versatile`.

## Features
- **12+ Supported Languages**: Python, JavaScript, TypeScript, Rust, Go, Java, C++, C#, Ruby, PHP, Swift, and Auto-Detect.
- **Idiomatic Logic Preservation**: Translates logic, idiomatic conventions, and syntax without breaking algorithms.
- **Syntax Highlighting**: Pre-rendered syntax highlighting with Highlight.js (github-dark-dimmed).
- **One-Click Copy**: Instant clipboard copying of translated output.
- **Dual-Pane IDE Layout**: Terminal aesthetic designed for developer workflow.

## Getting Started
1. Open `index.html` in your web browser.
2. Click the **Settings (⚙️)** button and enter your Groq API Key.
3. Paste your code into the source panel and choose your target language.
4. Click **Translate** to view the translated code.

## 🌐 Supported Programming Languages
- Python, JavaScript, TypeScript, Rust, Go, C++, C#, Java, Swift, Kotlin, PHP, Ruby

## ⌨️ Shortcuts
- `Ctrl` / `Cmd` + `Enter`: Run code translation
- `Escape`: Close settings dialog
